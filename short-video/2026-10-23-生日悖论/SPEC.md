# 生日悖论 · HyperFrames 试玩

GOAL:    看完的人意识到“23 个人就有一半概率撞生日”，直觉被打脸。
OUTPUT:  HyperFrames，1080 x 1920（竖屏），30 fps，中文男声配音（Qwen3-TTS 1.7B，音色 Dylan，见 voiceover.md）
TIME:    28 s x 30 = 840 帧；画面动作卡配音的词
LOOK:    孔版印刷（risograph）。纸：#F4D500 平涂黄，无渐变。
         墨 A #141414：所有要读的字和结构线。墨 B #C8221A：每帧只一个焦点（问号 / 253 / 50.7% / 99.9%），
         B 版偏移 3 px 套印不准（text-shadow 3px 3px 0 墨 A 20%）。
         标题 Noto Sans SC 900，140–220 px，字距 -4%；正文 Noto Sans SC 500，56 px。数字 Archivo Black，tabular-nums。
OBJECTS: 23 个人 = 23 个墨点围成一圈（直径 44 px）；“一对” = 两点之间一条 3 px 墨线。
MOTION:  进入 power4.out 0.35 s；数字计数 1.4 s power2.inOut 后定住；印章 back.out(2.2) 0.25 s；
         连线依次描出，2.0 s 内画完 253 条。
SHOTS:   000–162 钩子：第 0 帧已有“23 个人”；“有两人同一天生日”印出；红色“概率多大？”盖章。
         162–396 连线：23 点弹出 → 253 条线描出，底部计数 0→253“对”；说到“每一对”时描红其中一对。
         396–597 结果：50.7% 计数 + 进度条越过“一半”刻度。
         597–840 收尾：“70 人 → 99.9%”，“这就是生日悖论”。
BANNED:  暗色背景、光晕、渐变、玻璃卡片、全部居中淡入、字在被读时移动、角标 HUD、logo。
QA:      第 0、120、300、320、520、800 帧。
TEXT BAND: 所有文字在 y 168–1330 px 之内（抖音 UI 安全区）。
