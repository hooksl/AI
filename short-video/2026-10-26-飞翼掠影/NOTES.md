# 飞翼掠影 · 静图变动态

- 原图：用户提供的小红书图片（右下角水印「小红书号: 27796694238」），放在 `assets/source.jpg`，不进 git。
- 成片：1080×1440（3:4，与原图同比例），30 fps，10 秒，**首尾无缝循环**；带一段合成的高空风声。
- 云盘：`短视频/2026-10-26-飞翼掠影/飞翼掠影.mp4`

## 做法（全部本地代码，无 AI 视频模型）

| 步骤 | 脚本 | 说明 |
| --- | --- | --- |
| 抠飞翼 | `tools/segment.py` | 手画粗轮廓 → GrabCut → 左半边深色机身补全 → 轮廓高斯平滑、8× 超采样抗锯齿 |
| 底板 + 方向场 | `tools/prep.py` | 结构张量求条纹切向（先模糊到条纹尺度，压掉 JPEG 噪点的横竖偏向）；沿条纹两头取样补出飞翼下面的地表，高频按镜像位置取颗粒、保方差混合；水印抠成单独图层 |
| 渲染 | `tools/render.py` | 见下 |
| 风声 | `tools/ambience.py` | 频域造噪声再逆 FFT，信号天然首尾相接 |

`render.py` 每帧：
1. **地表流动**：两相流图（flow map）。沿条纹流线 RK2 回溯得到位移表，两层相位差半个周期交叉淡化，高频按权重保方差（指数 0.63，按实测两层相关性定的），避免交叉处发灰。周期 12 帧，整除 300 帧，所以能无缝循环。
   - 试过每像素错开相位：弯曲条纹被拉成“木纹”，放弃，改全局相位。
   - 速度近快远慢：`230 × (0.55 + 0.70·y/H)` px/s，朝左下（飞翼朝右上飞）。
2. **尾喷热浪**：喷口后方锥形区域，几组沿喷流方向传播的正弦扰动做折射位移。
3. **飞翼**：上下起伏 + 左右漂移 + 轻微偏航 ±0.55°，升高时略放大；明暗随“滚转”左右交替；2–6 s 有一道反光从机头扫到机尾。
4. **镜头**：1.045–1.057 倍呼吸缩放、亚像素级手持抖动、±0.12° 旋转；暗角、细颗粒。
5. **水印**：原样固定在屏幕原位置（保留原作者署名）。

所有周期运动都取「一个循环转整数圈」，第 299 帧 → 第 0 帧的差异与相邻帧相同（实测 6.2 vs 平均 5.7）。

## 复现

```bash
cp <原图> assets/source.jpg
python3 tools/segment.py && python3 tools/prep.py && python3 tools/ambience.py
python3 tools/render.py          # 约 5 分钟（4 核 CPU）
ffmpeg -i render/飞翼掠影_silent.mp4 -i render/ambience.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart render/飞翼掠影.mp4
```

依赖：`pip install opencv-python-headless scipy numpy`，ffmpeg。
